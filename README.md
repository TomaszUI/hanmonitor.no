# HAN Monitor — lokale strømdata fra norske AMS-målere

[Prosjektet](https://hanmonitor.no/?utm_source=github&utm_medium=referral&utm_campaign=project_readme) · [Komplett HAN-port guide](https://hanmonitor.no/han-port/) · [Velg HAN-leser](https://hanmonitor.no/beste-han-leser/) · [Alle guider](https://hanmonitor.no/guider/) · [Om prosjektet](https://hanmonitor.no/om-han-monitor/)

HAN Monitor er en HAN-leser under utvikling for norske AMS-målere. Målet er lokal visning av strømdata på hjemmenettet uten obligatorisk abonnement eller nødvendig skytjeneste.

## Prosjektstatus

| Område | Status |
| --- | --- |
| Kaifa/Nuri | Fungerer i prototypen |
| Aidon og Kamstrup | Trenger testing; kompatibilitet er ikke bekreftet |
| MQTT, lokalt API og Home Assistant | Planlagt, ikke ferdig integrasjon |
| Historikk | Må valideres |

Vi skiller mellom dokumenterte fakta, egne prototypetester og planlagte funksjoner. Se [Om HAN Monitor](https://hanmonitor.no/om-han-monitor/) og [testmetodikken](https://hanmonitor.no/testmetodikk/).

Dette repositoriet inneholder nettstedet, ikke firmware eller en installérbar Home Assistant-integrasjon. Produktet er ikke klart for bestilling.

## English

HAN Monitor is a prototype HAN reader for Norwegian AMS electricity meters. Kaifa/Nuri works in the prototype; Aidon and Kamstrup need testing. MQTT, a local API and Home Assistant integration are planned, not released. This repository hosts the website, not firmware. Technical feedback and testing interest are welcome through public issues. Please do not include personal data.
