Personvern

Sist oppdatert: 28. oktober 2026

HAN Monitor er i prototype- og betafase. Vi ønsker å samle inn minst mulig persondata og bruke dem kun til formålet de er gitt for.

Kontakt og interesse for testing

Direkte registrering på nettstedet er ikke åpnet. Du kan kontakte HAN Monitor på Facebook og sende en privat melding om interesse for testing. Opplysninger du velger å sende, brukes til å svare på henvendelsen og følge opp mulig testing av HAN Monitor. Oppgi gjerne målertype, om HAN-porten er aktivert og om du bruker Home Assistant. Ikke send målernummer, adresse eller sensitive opplysninger.

Facebook er en ekstern tjeneste. Når du bruker den, behandles profil- og meldingsopplysninger også av Meta etter Metas egne vilkår og personvernregler. Vi sender ikke innhold fra meldinger til besøksanalysen på dette nettstedet.

Besøksstatistikk

Vi bruker PostHog Cloud EU til privat besøksstatistikk. Analyse lastes bare når du velger «Tillat statistikk». Vi måler blant annet sidevisninger, trafikkilde, enhetstype og omtrentlig land/region. Prosjektet er konfigurert til å ikke lagre rå IP-adresser, og session replay er slått av. PostHog kan bruke førsteparts lagring/cookies etter samtykke for å skille besøk og økter. Vi publiserer ikke besøksstatistikken på nettsiden.

Ingen salg av persondata

Vi selger ikke personopplysninger til tredjeparter.

GitHub Pages

Nettsiden publiseres via GitHub Pages. Tekniske logger kan derfor behandles av GitHub i forbindelse med levering og sikkerhet av nettsiden.

Dine rettigheter

Du kan be om innsyn, korrigering eller sletting av personopplysninger du har sendt inn til prosjektet. Send forespørselen som en privat melding til HAN Monitor på Facebook.
