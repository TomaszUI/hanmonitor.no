Personvern

Sist oppdatert: 29. oktober 2026

HAN Monitor er i prototype- og betafase. Vi ønsker å samle inn minst mulig persondata og bruke dem kun til formålet de er gitt for.

Registrering som betatester

Du kan registrere interesse for betatesting direkte på nettstedet. Vi ber om navn, e-post, valgfri by/region, målertype, eventuell bruk av Home Assistant, hva du er interessert i og en valgfri kommentar. Ikke send målernummer, gateadresse eller sensitive opplysninger.

Opplysningene brukes bare til å vurdere og følge opp mulig betatesting eller senere interesse for HAN Monitor. Registreringen er frivillig og er ikke en bestilling eller garanti for plass i betatesten.

Skjemaet sendes via kryptert HTTPS-forbindelse til HAN Monitors private backend på Synology. Kontaktopplysninger og kommentar lagres kryptert i databasen. Dataene oppbevares så lenge de er nødvendige for oppfølging av betatesting, eller til du ber om retting eller sletting.

Kontakt via Facebook

Du kan også kontakte HAN Monitor på Facebook. Facebook er en ekstern tjeneste, og profil- og meldingsopplysninger behandles også av Meta etter Metas egne vilkår og personvernregler. Vi sender ikke innhold fra registreringsskjema eller private meldinger til besøksanalysen på nettstedet.

Besøksstatistikk

Vi bruker PostHog Cloud EU til privat besøksstatistikk. Analyse lastes bare når du velger «Tillat statistikk». Vi måler blant annet sidevisninger, trafikkilde, enhetstype og omtrentlig land/region. Prosjektet er konfigurert til å ikke lagre rå IP-adresser, og session replay er slått av. PostHog kan bruke førsteparts lagring/cookies etter samtykke for å skille besøk og økter. Vi publiserer ikke besøksstatistikken på nettsiden.

Ingen salg av persondata

Vi selger ikke personopplysninger til tredjeparter.

GitHub Pages

Nettsiden publiseres via GitHub Pages. Tekniske logger kan derfor behandles av GitHub i forbindelse med levering og sikkerhet av nettsiden.

Dine rettigheter

Du kan be om innsyn, korrigering eller sletting av personopplysninger du har sendt inn til prosjektet. Send forespørselen som en privat melding til HAN Monitor på Facebook og oppgi e-postadressen du brukte i registreringen, slik at vi kan finne riktig oppføring.
