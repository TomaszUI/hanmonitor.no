HAN-port og Home Assistant

Vil du bruke strømdata fra AMS-måleren i ditt eget smarthus? Vi utvikler HAN Monitor og ønsker innspill til en lokal løsning.

Er integrasjonen klar?

Nei. MQTT, lokalt API og Home Assistant-integrasjon er planlagt. Det finnes foreløpig ingen ferdig HAN Monitor-integrasjon du kan installere fra dette nettstedet.

Hva fungerer i prototypen?

Kaifa/Nuri fungerer i prototypen. Aidon og Kamstrup trenger testing før vi kan bekrefte kompatibilitet. Historikkfunksjonen må også valideres. Funksjoner og spesifikasjoner kan endres.

Hva ønsker vi å bygge?

Målet er å gjøre strømdata tilgjengelige på hjemmenettet uten obligatorisk abonnement eller nødvendig skytjeneste. Innspill om ønskede verdier, oppdateringsbehov og bruk i egne dashbord hjelper oss å prioritere.

Fortell hva du trenger

  • Vil du først og fremst se aktuell effekt eller følge historikk?
  • Er oversikt over fasene viktig for deg?
  • Hvilke automasjoner eller visninger ville du laget?

Bidra via GitHub

Du trenger ikke Facebook for å gi tekniske innspill. GitHub-innlegg er offentlige: oppgi bare målertype og generelle behov. Ikke send målernummer, adresse, e-post eller rå måledata.
