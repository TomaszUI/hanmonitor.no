HAN-port på Aidon AMS-måler

Aidon er en vanlig målerfamilie i Norden. For å bruke lokale måledata kobles kompatibelt utstyr til HAN-porten etter at porten er aktivert.

Status for HAN Monitor: Aidon er ikke ferdig validert. Vi søker testere med Aidon-målere for å kontrollere fysisk grensesnitt, datastrøm, stabilitet og variasjoner i norske installasjoner.

Hva kan HAN-porten brukes til?

HAN-porten er laget for lokal tilgang til måledata. Slike data kan brukes til å følge forbruk og effekt tettere enn via vanlige historiske måleravlesninger, og kan integreres med lokale energisystemer og smarthus.

Aktiver HAN-porten først

Før du kobler til en HAN-leser må porten vanligvis aktiveres av nettselskapet. Se vår steg-for-steg-guide for åpning av HAN-porten.

Aidon og Home Assistant

HAN Monitor planlegger MQTT og lokalt API for integrasjon med Home Assistant. Se HAN-port og Home Assistant for status og videre plan.
